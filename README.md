# Portfolio

A live site that is both a **PM portfolio** and a **classroom** for amateur PMs: strategy, prioritization, GTM, and the technical stack (frontend, APIs, identity, hosting, analytics).

The product spec is in [docs/PRODUCT.md](docs/PRODUCT.md).

## v1

Public home + Learn shell, passwordless auth, and two free lessons. Paid tracks, Stripe, Kafka, and Kubernetes come later.
